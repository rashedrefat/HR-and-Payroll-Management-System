## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
````

2. **Navigate to the project directory**

   ```bash
   cd Projects/Starter
   ```

3. **Install dependencies**

   ```bash
   npm install
   ```

4. **Start the development server**

   ```bash
   npm run dev
   ```

5. Open your browser and go to the URL shown in the terminal.
